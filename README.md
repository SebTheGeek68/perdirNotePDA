# Calepin PerdirNote

Webapp du téléphone qui accompagne **PerdirNote** : notes rapides, notes vocales et photos,
envoyées ensuite à l'ordinateur (AirDrop) pour y être classées.

- Ce dépôt ne contient **que le programme** (fichiers statiques). Aucune donnée d'établissement.
- Les notes restent sur le téléphone, chiffrées (AES-256, code à 6 chiffres), puis sont envoyées
  dans un fichier chiffré que seule la base PerdirNote liée peut ouvrir.
- Publié automatiquement par le script « Publier le calepin.command ». Ne pas modifier à la main.
